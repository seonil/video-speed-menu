# Chrome 웹 스토어 등록 자료

이름: Video Speed Menu

배포 방식: 미등록 / Unlisted (검색에 노출하지 않고 주소를 가진 사용자가 설치)

요약: HTML5 비디오를 최대 4배속으로 조절하고 실제 재생 속도를 확인하세요.

## 상세 설명

웹페이지의 HTML5 비디오 위에 배속 메뉴를 표시합니다. 영상 우측 상단의 버튼에서 원하는 속도를 선택하세요.

지원 배속: 1배속, 1.25배속, 1.5배속, 2배속, 3배속, 4배속.

주요 기능
- 영상 위에서 바로 재생 속도 선택
- 설정한 배속과 최근 영상 진행량으로 계산한 실측 배속 표시
- 선택한 배속 유지 옵션
- 여러 영상이 있으면 화면에 보이는 재생 영상과 크기를 기준으로 대상 선택

사용 방법
1. 설치한 뒤 이미 열린 비디오 페이지를 새로고침합니다.
2. 영상을 재생하고 우측 상단의 배속 버튼을 누릅니다.
3. 원하는 속도를 고릅니다. 실측 배속은 약 2초부터 표시됩니다.
4. 기본 속도로 돌아가려면 1배속을 선택합니다.

일반 HTTP와 HTTPS 페이지의 HTML5 비디오를 대상으로 합니다. 사이트의 플레이어 구현이나 전체화면 방식에 따라 메뉴가 보이지 않거나 속도 적용이 제한될 수 있습니다. 모든 사이트에서 동작을 보장하지 않습니다.

외부 서버 통신, 개인정보 수집, 광고 및 분석 도구를 포함하지 않습니다.

## 개인정보 공개 항목

단일 목적: 웹페이지의 HTML5 비디오 재생 속도를 1배속부터 4배속까지 조절하고 실측 배속을 표시합니다.

호스트 접근 이유: 페이지와 포함된 프레임 안의 HTML5 비디오를 탐색하고, 영상 위치에 배속 메뉴를 표시하며, 선택한 재생 속도를 적용하기 위해 HTTP 및 HTTPS 페이지에서 콘텐츠 스크립트가 실행되어야 합니다. 비디오의 재생 상태와 진행 시간은 기기 안에서만 처리되며 수집하거나 외부로 전송하지 않습니다.

원격 코드 사용: 사용하지 않음. 실행 코드는 패키지에 포함되어 있음.

사용자 데이터 수집: 없음.
